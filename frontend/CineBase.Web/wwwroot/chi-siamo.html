Cinema67

Piattaforma dimostrativa di gestione cinema

Il Progetto

Cinema67 è un'applicazione web full-stack sviluppata come progetto dimostrativo per un sistema completo di gestione cinema.

Include prenotazione biglietti, gestione programmazione, e-commerce (shop & food), membership, gift card, feste private, dashboard amministrativa, e molto altro.

Tecnologie

  • Backend: ASP.NET Core 9 Minimal API
  • Database: MariaDB + Entity Framework Core
  • Frontend: HTML/CSS/JavaScript + Tailwind CSS
  • Pagamenti: Stripe
  • Auth: JWT + OAuth (Google/Microsoft)
  • Hosting: Oracle Cloud Always Free
  • Container: Docker + Docker Compose

Attenzione: Cinema67 è un progetto fittizio. I film, le sale cinematografiche, gli orari e i prezzi non corrispondono a realtà. Questa applicazione è stata sviluppata esclusivamente a scopo dimostrativo e didattico.
