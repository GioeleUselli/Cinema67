## 💡 Domande Probabili & Risposte

### "Come gestite i conflitti di seat?"
**Risposta**: Usiamo hold con TTL di 10 minuti + database transaction con isolamento SERIALIZABLE. Se uno user tiene premuto il browser per 11 minuti, il seat torna disponibile.

### "Come prevent double-charging?"
**Risposta**: Stripe Idempotency Keys + unique constraint nel database su ordine. Anche se la richiesta viene mandata 2 volte, viene processata 1 sola volta.

### "Come scalate?"
**Risposta**: Horizontal scaling - aggiungiamo istanze ASP.NET dietro Nginx load balancer. MySQL replica per read-heavy queries. Redis cluster per caching e sessions.

### "È sicuro?"
**Risposta**: Sì - Stripe PCI-DSS, JWT authentication, AES-256 encryption, GDPR compliant, audit logging, OWASP Top 10 covered.

### "Quanto costa mantenere?"
**Risposta**: EUR 1,550/mese (server, hosting, email, monitoring). EUR 0 in licensing (tutto open source). Break-even a 3,100 ticket/mese.
